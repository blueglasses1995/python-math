# レッスン3: 複素数 (Complex Numbers)

## 学習目標

複素数の基本から複素関数の可視化まで、複素数の世界を探索します。

### 学習内容

1. **複素数の基本**
   - 実部と虚部
   - 絶対値と偏角
   - 共役複素数

2. **複素数の演算**
   - 四則演算
   - 累乗と平方根

3. **複素平面（ガウス平面）**
   - 複素数の幾何的表現
   - 単位円上の複素数

4. **極形式と指数形式**
   - z = r(cos θ + i sin θ)
   - z = r·e^(iθ)
   - 直交形式との変換

5. **オイラーの公式**
   - e^(iθ) = cos θ + i sin θ
   - オイラーの等式: e^(iπ) + 1 = 0
   - 複素数による回転

6. **複素関数**
   - z², e^z, 1/z, sin(z)
   - 位相と大きさの可視化
