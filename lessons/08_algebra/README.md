# レッスン8: 代数学 (Algebra)

## 学習目標

抽象代数学の基礎から暗号化への応用まで、代数構造とその実用性を学びます。

### 学習内容

1. **群論の基礎**
   - 群の定義と公理
   - 加法群と乗法群
   - 剰余群
   - ケイリー表
   - 巡回群

2. **対称群**
   - 置換群
   - S_nの構造
   - 置換の合成

3. **環と体**
   - 環の定義
   - 体の定義
   - 有理数体、実数体

4. **多項式環**
   - R[x]の構造
   - 多項式の演算
   - 多項式の除法

5. **有限体（ガロア体）**
   - GF(p)の構造
   - 加法表と乗法表
   - 有限体の応用

6. **実務応用: 暗号化**
   - RSA暗号の数学的基礎
   - 素数と剰余演算
   - モジュラ逆元
   - 公開鍵暗号の仕組み

7. **実務応用: 誤り訂正符号**
   - ハミング符号
   - 線形符号理論
   - エラー検出と訂正
   - 通信における応用

8. **実務応用: ブロックチェーン**
   - 暗号学的ハッシュ関数
   - チェーン構造
   - データ整合性の保証

## 実務への応用

### 暗号通信
- **RSA暗号**: インターネット通信（HTTPS）
- **楕円曲線暗号**: ビットコイン、電子署名
- **AES**: ファイル暗号化、VPN

### データ通信
- **誤り訂正符号**: CD/DVD、QRコード
- **ハミング符号**: メモリのECC
- **リードソロモン符号**: 衛星通信

### ブロックチェーン
- **暗号学的ハッシュ**: データ整合性
- **マークル木**: 効率的な検証
- **デジタル署名**: トランザクション認証

### 量子コンピューティング
- **群論**: 量子ゲート
- **有限体**: 量子誤り訂正
