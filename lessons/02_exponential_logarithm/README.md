# レッスン2: 指数関数と対数関数 (Exponential and Logarithmic Functions)

## 学習目標

指数関数と対数関数の基本と実世界での応用を学びます。

### 学習内容

1. **指数関数の基本**
   - e^x (自然指数関数)
   - a^x (一般の指数関数)
   - オイラー数 e

2. **対数関数の基本**
   - 自然対数 ln(x)
   - 常用対数 log10(x)
   - 二進対数 log2(x)

3. **指数・対数の法則**
   - 指数法則: e^a * e^b = e^(a+b)
   - 対数法則: ln(xy) = ln(x) + ln(y)
   - 逆関数の関係: ln(e^x) = x

4. **成長と減衰**
   - 指数成長（人口増加）
   - 指数減衰（放射性崩壊）

5. **実世界の応用**
   - 複利計算
   - ニュートンの冷却法則
   - 対数目盛の使い方
