# レッスン4: 微分 (Calculus - Differentiation)

## 学習目標

微分の基礎から多変数微分まで、微積分学の基本を学びます。

### 学習内容

1. **数値微分**
   - 前進差分法
   - 中心差分法
   - 精度と誤差の分析

2. **記号微分（SymPy）**
   - 解析的な導関数の計算
   - 多項式、三角関数、指数関数の微分
   - 高階導関数

3. **導関数の幾何的意味**
   - 接線の傾き
   - 極値の検出（臨界点）
   - 凸性と二階導関数

4. **偏微分**
   - 多変数関数の偏導関数
   - 二階偏微分
   - 混合偏導関数

5. **勾配ベクトル**
   - 勾配の幾何的意味
   - 等高線と勾配の関係
   - サドルポイント

## 実行方法
