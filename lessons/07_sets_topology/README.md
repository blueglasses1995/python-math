# レッスン7: 集合と位相 (Sets and Topology)

## 学習目標

集合論の基礎から位相空間の概念まで、数学の基礎となる構造を学びます。

### 学習内容

1. **集合の基本操作**
   - 和集合、積集合、差集合
   - 部分集合と べき集合
   - 直積
   - ド・モルガンの法則

2. **ベン図**
   - 2つの集合の関係
   - 3つの集合の関係
   - 集合演算の可視化

3. **写像と関数**
   - 単射（injection）
   - 全射（surjection）
   - 全単射（bijection）
   - 逆写像

4. **距離空間**
   - ユークリッド距離（L2ノルム）
   - マンハッタン距離（L1ノルム）
   - チェビシェフ距離（L∞ノルム）
   - 距離の公理

5. **開集合と閉集合**
   - 開区間と閉区間
   - 開球と閉球
   - 内部、境界、外部
   - 閉包

6. **連続性**
   - 連続関数の定義
   - 不連続の種類
   - ジャンプ不連続
   - 除去可能不連続
   - 無限不連続
