# レッスン5: 線形代数 (Linear Algebra)

## 学習目標

線形代数の基本から主成分分析、そしてDeep Learningへの応用まで、ベクトル空間と線形写像を深く理解します。

### 学習内容

1. **ベクトルの基本**
   - ベクトルの加算・減算
   - スカラー倍
   - 内積とノルム
   - ベクトル間の角度

2. **行列の基本操作**
   - 行列の加算・乗算
   - 転置行列
   - 逆行列
   - 行列式とトレース

3. **線形変換**
   - 回転、拡大縮小、せん断、反射
   - 線形変換の幾何的理解
   - 基底ベクトルの変換

4. **固有値と固有ベクトル**
   - 固有値問題 Av = λv
   - 固有ベクトルの意味
   - 対角化

5. **特異値分解（SVD）**
   - A = UΣV^T
   - 特異値と特異ベクトル
   - 行列の近似

6. **主成分分析（PCA）**
   - データの中心化
   - 共分散行列
   - 次元削減
   - 寄与率の計算

7. **ベクトル空間の詳細**
   - ベクトル空間の定義と公理
   - 部分空間
   - 基底と次元
   - 線形独立と線形従属
   - スパン（張る空間）

8. **線形写像の詳細**
   - 線形写像の定義
   - 核（Kernel）と像（Image）
   - 階数定理（Rank-Nullity Theorem）
   - 単射・全射・全単射
   - 同型写像と準同型写像

9. **実務応用: Deep Learning**
   - ニューラルネットワークの全結合層
   - バッチ処理における行列演算
   - 注意機構（Attention Mechanism）
   - 単語埋め込み（Word Embeddings）
   - コサイン類似度
   - PCAによる次元削減
   - SVDと推薦システム

## 実務への応用

### Deep Learning
- **全結合層**: y = Wx + b（線形変換）
- **畳み込み層**: 行列演算の効率的な実装
- **注意機構**: QK^T/√d_k による類似度計算
- **バッチ正規化**: 統計量の行列計算

### 自然言語処理（NLP）
- **Word2Vec/GloVe**: ベクトル空間への単語の埋め込み
- **Transformer**: 注意機構の多層適用
- **文書類似度**: コサイン類似度による比較
- **次元削減**: PCAやSVDによる特徴抽出

### 推薦システム
- **協調フィルタリング**: 行列分解（SVD）
- **潜在因子モデル**: 低ランク近似
- **類似度計算**: 内積とコサイン類似度

### コンピュータビジョン
- **画像変換**: アフィン変換（回転・拡大縮小）
- **特徴抽出**: PCAによる次元削減
- **顔認識**: 固有顔（Eigenface）法

### データサイエンス
- **次元削減**: PCA、t-SNE
- **クラスタリング**: K-means（重心計算）
- **異常検知**: マハラノビス距離
