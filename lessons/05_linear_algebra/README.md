# レッスン5: 線形代数 (Linear Algebra)

## 学習目標

線形代数の基本から主成分分析まで、ベクトルと行列の世界を学びます。

### 学習内容

1. **ベクトルの基本**
   - ベクトルの加算・減算
   - スカラー倍
   - 内積とノルム
   - ベクトル間の角度

2. **行列の基本操作**
   - 行列の加算・乗算
   - 転置行列
   - 逆行列
   - 行列式とトレース

3. **線形変換**
   - 回転、拡大縮小、せん断、反射
   - 線形変換の幾何的理解
   - 基底ベクトルの変換

4. **固有値と固有ベクトル**
   - 固有値問題 Av = λv
   - 固有ベクトルの意味
   - 対角化

5. **特異値分解（SVD）**
   - A = UΣV^T
   - 特異値と特異ベクトル
   - 行列の近似

6. **主成分分析（PCA）**
   - データの中心化
   - 共分散行列
   - 次元削減
   - 寄与率の計算
