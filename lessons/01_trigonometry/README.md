# レッスン1: 三角関数 (Trigonometric Functions)

## 学習目標

このレッスンでは、Pythonを使って三角関数の基本を学びます。

### 学習内容

1. **基本的な三角関数**
   - sin, cos, tan の計算
   - 度数法とラジアン

2. **三角関数のグラフ**
   - 周期性の理解
   - 振幅と位相

3. **単位円**
   - 単位円上の点と三角関数の関係
   - 角度と座標の対応

4. **逆三角関数**
   - arcsin, arccos, arctan
   - 定義域と値域

5. **三角恒等式**
   - sin²(x) + cos²(x) = 1
   - 加法定理の検証

## 実行方法

```bash
cd lessons/01_trigonometry
python lesson.py
```

## 必要な知識

- 基本的なPythonの構文
- 角度の概念（度数法とラジアン）
