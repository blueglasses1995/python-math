# レッスン6: 統計学 (Statistics)

## 学習目標

統計学の基礎から仮説検定まで、データ分析の基本を学びます。

### 学習内容

1. **記述統計**
   - 平均、中央値、最頻値
   - 分散と標準偏差
   - パーセンタイル
   - 歪度と尖度

2. **確率分布**
   - 正規分布
   - 二項分布
   - ポアソン分布
   - 指数分布
   - t分布
   - カイ二乗分布

3. **中心極限定理**
   - サンプリング分布
   - 標本平均の分布
   - サンプルサイズと分布の形状

4. **相関と回帰**
   - Pearson相関係数
   - Spearman相関係数
   - 線形回帰
   - 決定係数（R²）
   - 残差分析

5. **仮説検定**
   - 1標本t検定
   - 2標本t検定
   - カイ二乗検定
   - p値と有意水準
   - 信頼区間
   - 検出力分析
